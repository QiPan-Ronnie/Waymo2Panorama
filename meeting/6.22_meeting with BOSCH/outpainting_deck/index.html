Ground Outpainting · Method

Borrowing real ground from time

✕
Not a painter. It does not imagine a plausible ground.
✓
A detective. Which other frame actually photographed this ground?
01 · LOCATE

The hole

ERP nadir is black or blocked by the ego body. Each hole pixel → a ray → meets the LiDAR ground → a real 3D point X.

→
02 · FIND FRAMES

Who saw X?

Search the whole log for frames that observed X — selected by ego distance, not time.

→
03 · FILTER

Reject liars

Three gates: source hood / trunk (two-box), dynamic objects (cars, people), shutter-time mismatch (EMC).

→
04 · VOTE

One real pixel

6 sources → median to check agreement → keep the nearest-to-median real pixel. Never average — averaging smears lane lines.

→
05 · BE HONEST

Abstain

Sources disagree, or only grazing views exist → low-pass / flat fill. Never invent a lane line.

HOW WE
PICK FRAMES
✕ By time fails. A ±time window finds 0 usable frames when the ego idles 9.5 s at a red light.
✓ By distance. Keep frames 5–58 m away · bucket every 5 m · 3 time-nearest per bucket → every viewing angle, freshest exposure.

Every filled pixel is a real pixel some frame actually captured — where none did, we abstain.

Ground Outpainting · Open Issues

What's wrong — and our hypotheses

These are hypotheses — and the data already refuted one of mine. I claimed the near-nadir is a universal physical blind spot. But the coverage maps show most frames have 6-source, ~11° coverage near the ground. The blind spot is local, not universal — so each guess below carries a confidence tag.
①White-blob / soft ≈ processing self-inflicted, not missing data. Over-low-pass on well-covered ground.FIX · MED-HI
②Smear / car-front ghost / color bleed = occlusion not verified (source & target). Add LiDAR z-buffer + box gate.FIX · MED
③Lavender cast (bmw) = real grazing Fresnel sky reflection. Half-physical; only tone-harmonize.SEMI · MED-HI
④Blind patches on some frames truly unseen (open / low-motion). Physically unrecoverable — but local.PHYS · MED
⑤Middle band is independent & basically solved (off ≡ fill, pixel-identical) → Route-2 sidesteps ①②④.ARCH · HIGH
