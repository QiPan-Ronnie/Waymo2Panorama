1. **Fundamental Or Fixable**

The half-intensity seam ghost is implementation-caused. The decisive reason is simple: if you output `0.5*A(x) + 0.5*B(x-d)` with residual displacement `d > ~1 px`, you have explicitly rendered two copies. That is not a physics limit; it is the blend operator doing exactly what it mathematically must do.

But your stronger claim is too loose. “Never average” eliminates translucent double images; it does not guarantee a correct ego-centered panorama. Some seam pixels are fundamentally not recoverable as clean source-faithful ego pixels because of occlusion, disocclusion, bad depth support, non-Lambertian surfaces, and the fact that ego recentering is a ~2 m radial viewpoint shift, not just the 21-26 cm adjacent-camera baseline.

Also: your view-interp path is suspect. Interpolating between adjacent cameras with shift `w_j/(w_i+w_j)` creates a view along the small adjacent baseline. The target is the ego origin, roughly 2 m away from each camera center. That is a different viewpoint problem. So yes, the ghost is fixable by single-source selection, but the whole seam is not magically cleanable.

2. **Where Single-Source-After-Align Still Fails**

It fails where the two views do not contain the same visible surface.

Concrete bad cases:

- Foreground/background depth edges: one camera sees foreground, the other sees background. Flow may align the wrong layer.
- Near cars/poles/walls crossing the seam: the ego-center correction can be many degrees at close range. At 5 m, `2/5 ~= 0.4 rad ~= 23 deg`, already larger than your 18.6 deg overlap wedge.
- Disocclusion from the ego center: the correct ego pixel may correspond to a surface neither adjacent camera cleanly observed.
- Reflective glass, shiny cars, exposure differences, rolling shutter, calibration error.
- kNN LiDAR depth bleeding across object boundaries.

A hard cut then shows a step, tear, or object truncation instead of a ghost. For AV training data, that is usually better than a faint ghost. A ghost creates physically impossible semi-transparent duplicated objects. A hard seam is ugly but source-faithful and can be masked or source-labeled.

3. **Reproject-To-True-Centre Then Pick One**

Yes, picking one after true ego reprojection is better than averaging, but only under strict conditions.

Your distinction from rotation-only selection is valid: selecting between two rotation-only copies is geometrically wrong because both are camera-centered. Selecting between two correctly ego-reprojected copies is valid because both should land at the same ego pixel.

But this only holds if:

- the dense depth is correct for the ego ray,
- z-buffering chooses the visible surface,
- both cameras actually see that surface,
- the reprojection convention is correct,
- no depth completion crosses foreground/background edges.

If depth is slightly wrong, pick gives a sharp but misregistered pixel. Average gives a blurred or ghosted wrong pixel. Pick is still usually preferable for source-faithful data. Average only beats pick when the two samples are already subpixel-aligned and are genuinely the same surface, or when you are blending only low-frequency color/exposure, not geometry.

4. **Minimal Recipe That Beats L1 Without Ghost**

The minimal viable recipe is:

1. Build L1 as the fallback.
2. In seam bands, create ego-centered candidates from each camera using dense depth, z-buffering, and visibility masks.
3. Reject aggressively: no depth support, high depth gradient, bad z consistency, high RGB/gradient residual, bad FB flow, or occlusion ambiguity means no blend.
4. Choose exactly one high-frequency source per pixel with a stable seam label map, preferably graph-cut/dynamic-programming over the 18.6 deg wedge rather than noisy per-pixel argmax.
5. Use flow only to test/align/cost the loser against the winner. Do not average geometry.
6. Apply only low-frequency color correction across the cut: blur/gain-field/Lab lowpass. The high-frequency image must come from one source.

The honest ceiling is the agreement/visibility mask. Cleanly singled pixels are those where one source is valid or two ego-reprojected sources agree after z-buffering. Everything else must fall back to L1, hard cut, or masked output. On this rig, far static facades/road should be cleanable; close occluders spanning the whole wedge are not. Do not promise 100% clean seams.

5. **CPU-Only Kill-Test**

Run an oracle A/B test with the same compositor code:

- Synthetic phase: render two adjacent pinhole cameras and the ego-center target from a simple textured scene: road plane, wall plane, foreground box/car shape, known depths, known extrinsics. Use true dense depth. Compare:
  - rotation-only L1,
  - ego-reproject + average,
  - ego-reproject + pick-one,
  - ego-reproject + pick-one + lowpass color blend.
  
  If true-depth pick-one ghosts, your implementation is wrong: coordinate convention, z-buffer, splat/remap, mask, or accidental blending.

- Real phase: on actual seam pairs, build a LiDAR-supported “same surface” mask: both cameras valid after ego reprojection, z-consistent, RGB/gradient residual low. On that mask, compare average vs pick-one. If average ghosts and pick-one does not, your bug is blending/gating. If the clean mask is tiny on the bad seams, the unrecoverable fraction is fundamental coverage/occlusion, not a de-doubling bug.

- Perturbation phase: deliberately shift one candidate by 0, 1, 2, 4, 8 px and compare average vs pick. The ghost should grow with blend displacement. That calibrates the residual threshold at which averaging must be forbidden.

Verdict: **GHOST = IMPLEMENTATION (fixable by single-source)**; the next experiment is the oracle true-depth ego-reproject A/B: average vs pick-one, using identical masks and compositor code.
