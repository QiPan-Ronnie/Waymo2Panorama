### 2. Patched it to v0.1.1 mid-test
- During the E2E test, `mcp__acq__submit_job` wrote the spec file successfully and `git add` succeeded, but the server died on `git commit` with `MCP error -32000: Connection closed`. Root cause: `subprocess.run(text=True, timeout=60)` raised an unhandled exception (likely Unicode decode or timeout) which killed the FastMCP process.
- Fix in `client._run_git`: bytes mode + manual `errors='replace'` decode; catches `TimeoutExpired`, `FileNotFoundError`, all other Exception. Never raises.
- Fix in `mcp_server`: `@_safe_tool` decorator on every tool — even if a tool body raises, returns `{ok: False, error, traceback}` instead of crashing the server.
- v0.1.1 commit `c73678f` pushed to fork.
- **To activate**: restart Claude Code (uvx auto-rebuilds since source hash changed).
